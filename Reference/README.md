This directory preserves original research and product-concept inputs. Its name
predates the current documentation structure. Do not confuse it with the
[`docs/reference/` section](../docs/reference/index.md), which contains current
Aptus interface and state reference pages.

Presence in this directory does not mean a method is implemented, selectable,
compatible, calibrated, or supported. Current runtime authority comes from the
typed method registry, planner, compiler, validator, and tests.

## Intake rule

Before a retained idea enters Aptus, it needs a primary source, precise method
category, pinned implementation, compatibility rules, estimator, compiler,
checkpoint and export contracts, tests, and target-host evidence. The complete
checklist is in the [research index](../docs/research/index.md).

## Preservation rule

The historical source bodies remain unchanged. Status warnings and this index
provide the authority boundary. Record future corrections in a dated
reconciliation note instead of silently rewriting the source packet.
